Save this circuit

A small .json file you can hand out, collect or open again later.
Or save it as a simulator
A page of its own that opens straight into Run mode: students can press the buttons, change the speed and reset it, but cannot change the circuit. One file, nothing to install. (To change it later, open the simulator file here.)
Or open it in Print Builder
Opens Print Builder in a new tab with this circuit drawn as a print, ready to tidy up and print. Bring it back with Open in Circuit Builder there: anything only Circuit Builder knows (colours, faults, process values) comes back with it.
Or share it as a code
Paste it into an email, a document or your class page. Anyone can open it with Open → Paste a code.
