the installed app, is always `Circuit_Builder.html` at the top of the repository.

To go back to a backup, copy its `Circuit_Builder.html` up over the one at the top of the repository (for the Print Builder, its `print-builder/Print_Builder.html` over `print-builder/index.html`; for the Fault Finder, its `fault-finder/index.html` and manifest over the ones in `fault-finder/`).

From Nov 16, 2026 a backup holds one zip of the whole source, `source_<commit>.zip`, which includes the repo's `shared/` folder once that folder is part of what is on main. The Nov 15 backups hold the pages only; the commit each was built from is named above, so its source is in the git history.
